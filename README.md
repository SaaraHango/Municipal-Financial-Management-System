
# Municipal Financial Management System (MFMS)

## 📌 Project Overview
This project is the foundation version of a Municipal Financial Management System (MFMS), developed in **ANSI C (C99)** for the course **PAP521S - Programming in Practice** at Namibia University of Science and Technology.

The system demonstrates the use of core C programming concepts such as input/output, variables, operators, decisions, loops, arrays, strings, and functions.

##  System Features
- **Employee Management:** Add, display, search employees, calculate salary.
  
- **Budget Management:** Enter departmental budgets, expenditures, calculate remaining budget, check status.
  
- **Supplier Management:** Add, display, search suppliers, compare supplier info.
  
- **Asset Management:** Register municipal assets, display and search asset information.
  
- **Reports:** Generate employee, budget, supplier, and asset reports.
  
- **Validation:** Prevent invalid input (negative salaries, empty names, invalid menu choices).
